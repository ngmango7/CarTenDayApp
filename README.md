# CarTenDayApp Android App

This repo now includes a minimal Android project that mirrors the 10-day vehicle maintenance checklist app.

## Build APK
Open the project in Android Studio and choose:

- Build > Build Bundle(s) / APK(s) > Build APK

Or, if you have Gradle installed locally:

```bash
gradle assembleDebug
```

## Notes
The project is configured as a standard Android app using Kotlin and Material components.
